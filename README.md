# EPS-TOPIK Bangla Flutter App (Auto APK Build Enabled)

এই ফোল্ডারে আপনার **Flutter** অ্যাপের সম্পূর্ণ সোর্স কোড এবং স্বয়ংক্রিয়ভাবে **`.apk` ফাইল** তৈরির জন্য **GitHub Actions Workflow** (`.github/workflows/build_apk.yml`) দেওয়া আছে।

## কম্পিউটারে কিছু ইনস্টল না করেই কীভাবে সরাসরি `.apk` ফাইল পাবেন:
1. এই ফোল্ডারের সব ফাইল আপনার GitHub রিপোজিটরি (`https://github.com/mdbanna/EPS-Learning.git`)-তে আপলোড বা Push করুন।
2. আপনার GitHub রিপোজিটরির উপরের **Actions** ট্যাবে যান।
3. সেখানে **"Build Android APK (Flutter)"** নামের ওয়ার্কফ্লোটি নিজে থেকেই রান হবে (অথবা **Run workflow** বাটনে ক্লিক করুন)।
4. ৩–৪ মিনিটের মধ্যে বিল্ড শেষ হলে নিচে **Artifacts** সেকশনে **`EPS-TOPIK-Bangla-App-APK`** নামে সরাসরি আপনার **`.apk` ফাইল** ডাউনলোড করার লিংক পেয়ে যাবেন!
